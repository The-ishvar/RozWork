# RozWork Mobile

A React Native + Expo mobile experience for the existing RozWork MERN backend.

## Run locally

1. Install dependencies: `npm install`
2. Start the backend from the server folder: `npm --prefix ../server run dev`
3. Start the mobile app: `npm start`

The app uses the existing authentication, jobs, bookings, notifications, purchases, and admin endpoints from the RozWork backend.
